# 孕检规划与关键指标解读

中国大陆通用规划版＋孕前糖尿病重点补充 · 联网核验日期：2026-11-01

二次审核：[血糖场景区分、孕前糖尿病路径及冲突记录](../reviews/0a.孕检HTML二次审核记录.md)。

产检同时关注孕妇健康、胎儿结构与生长、分娩准备。安排时先锁定有时间窗的筛查，再把常规复诊、结果复核与后续处理串起来。**完成检查后，还要确认医生已经解读报告、异常是否需要转诊、下次何时复查。**

本表主要面向单胎、没有已知严重合并症的孕妇。双/多胎、辅助生殖、既往不良孕产史、慢性病、筛查异常等需要单独排期。这里帮助规划和理解报告，不能单凭表格自行诊断或调整治疗。

`13+6周` 表示孕13周6天；孕周以产科核定值为准，不要根据后期胎儿大小反复自行修改预产期。依据包括国家卫健委2025年产前筛查文件、专项指南/共识和公立医院就诊说明；逐条纠错和来源版本见[双向核验记录](../reviews/0a.孕检双向核验记录.md)。

## 一、先按孕周安排检查

“按指征”表示由病史、风险和既往结果决定，并非所有人都要增加该项目。筛查窗口不是“最后一天再去”的预约建议，应提前联系医院。

| 时间 | 做什么 | 检查意义 | 报告重点与下一步 |
| --- | --- | --- | --- |
| 确认怀孕后尽早；早孕超声常见约6–8周 | 早孕就诊、病史与用药评估；按医生安排超声 | 确认妊娠位置、存活情况、胎数及孕周 | 看宫内妊娠、胎芽/心搏、头臀长CRL等；检查过早可能需复查。有腹痛、出血等应及时就医，不等到预定周数。[孕期保健指南][s-general] |
| 孕13周前 | 社区建《母子健康手册》、完成首次产前评估；尽早确认分娩医院建档要求 | 建立基线、识别高危因素、衔接后续保健 | 社区建册和医院建档是两个流程；首次常见血常规、尿常规、ABO/RhD、肝肾功能、血糖和感染筛查，具体由医院开单。[公共卫生规范修订说明][s-public]、[首诊项目][s-general] |
| 首次产检，优先孕早期 | 艾滋病、梅毒、乙肝筛查；阳性/可疑者进入确认及专科管理 | 尽早启动母婴传播预防 | 看具体检测项目及确认状态，不能把初筛“有反应”直接当完整诊断。晚孕复查按风险和当地流程安排。[三病服务方案][s-infection] |
| 孕11–13+6周 | NT等早期超声；按已选择方案做早期血清学筛查 | 早期发现结构异常线索、评估相关染色体异常风险 | NT数值、孕周、报告是否提示增厚/其他异常；早期血清学看综合风险。异常需产前诊断咨询。[2025超声要点][s-ultrasound]、[2025血清学要点][s-serum] |
| 孕12–22+6周为适宜窗口 | 根据咨询选择NIPT，即无创DNA产前筛查 | 评估21、18、13三体风险 | 看低风险/高风险/未获得结果及检测范围；高风险须进入诊断路径。不是每个人都要把唐筛与无创重复做全套。[2025无创知情要点][s-nipt] |
| 孕15–20+6周 | 按所选方案做中期血清学筛查，常称“中唐” | 评估21、18三体及开放性神经管缺陷风险 | 看风险比、各项目、样本日期和孕周；不是只看AFP或hCG单个箭头。已做其他筛查者，向医生确认还需补哪类评估。[2025血清学要点][s-serum] |
| 孕中期，按诊断中心安排；常见约16–22+6周 | 有指征时行羊膜腔穿刺及相应遗传学检测；更早阶段可能选择绒毛取样 | 对特定遗传学问题进行诊断 | 先问取样后具体做核型、染色体微阵列还是针对性基因检测，不能把“羊穿”理解为检查所有遗传病。[卫健委产前诊断说明][s-diagnosis] |
| 孕20–24+6周 | 中孕期系统超声，俗称“大排畸” | 系统观察常见严重胎儿结构畸形及附属物 | 看检查是否完成、哪些部位显示受限、是否需复查或专科超声。正常结果不等于排除全部出生缺陷。[2025超声要点][s-ultrasound] |
| 孕24–28周 | 常规75g OGTT；复查贫血等项目按医嘱合并安排 | 识别妊娠期糖尿病；继续评估孕妇状态 | 服糖前空腹、服糖后1小时、2小时共三个血糖值；任一达到诊断界值即需医生处理。[国家行业标准][s-ogtt] |
| 约孕28–32周 | 常规复诊；按安排评估胎儿生长、羊水、胎位和胎盘，复查血/尿等 | 关注生长趋势与孕晚期母体风险 | 估重EFW/腹围AC的百分位及变化，比“偏大偏小几天”更有解释价值。小于第10百分位需进一步评估。[生长共识][s-growth] |
| 孕晚期约34–36周起，或医院另定 | 确认NST胎心监护起始时间；高风险可提前 | 评估当时的胎儿宫内状态 | 不是所有孕妇32周统一开始；看医生对完整曲线的判读和复查安排。[胎监说明][s-nst]、[机构排期示例][s-hospital] |
| 孕35–37周 | 阴道下1/3联合直肠GBS筛查；特定病史者由医生直接规划预防 | 为分娩时预防新生儿早发型GBS感染做准备 | 阳性主要影响临产/破膜后的产时抗生素安排，不等于自行在家吃药；阴性超过5周仍未分娩时问是否重查。[中国GBS共识][s-gbs] |
| 约孕36周后至足月 | 复诊通常更密集，常见每周；按医嘱进行胎监、必要超声与分娩评估 | 关注胎位、胎儿状态、母体风险，确定就诊及分娩安排 | 带好GBS结果、血型/抗体信息、重要异常与既往手术记录。每周复诊不等于每次都做阴道内诊或宫颈评分。[机构排期示例][s-hospital]、[保健指南][s-general] |
| 到预产期仍未分娩 | 按医院缩短随访间隔，提前讨论引产或住院计划 | 避免超过预定评估时间而失访 | 不自行等到42周；需要结合实际孕周、胎儿与孕妇情况决定下一步。[保健指南][s-general] |

**复诊次数和检查窗口是两件事。**2018年国内保健指南给低风险单胎的整体框架为7–11次，高危增加；一些医院按孕28周前约4周一次、28–36周约2周一次、36周后约1周一次安排。公共卫生服务中的“五次节点”不能理解为整个孕期只需检查五次。[保健指南][s-general]、[宣武医院路径][s-hospital]

**时间窗错过后，应尽快联系产科重新规划。**不能用晚些时候的普通B超冒充错过的NT。NIPT超过22+6周也不是绝对无法做，但国家2025知情条款明确提示可能错过最佳产前诊断及后续处理时间，不应因此拖延。[2025无创知情要点][s-nipt]

## 二、每次复诊要确认什么

常规复诊重点是询问症状和既往结果，测量血压、体重，按孕周检查宫高、胎心、胎位等；血常规、尿检和超声按节点、病情及医院方案安排，**不是每次都重复全部抽血和B超**。[保健指南][s-general]

每次离开门诊前，确认五件事：

1. 今天检查解决了什么问题，有无未完成或待出结果的项目。
2. 报告是否已经由产科医生看过，异常是复查、转诊还是继续观察。
3. 下一次日期和要做的项目，是否提前开单或预约。
4. 是否空腹、何时服药、如何留样，以本次检查单的要求为准。
5. 出现哪些症状应提前联系医院或急诊。

## 三、孕妇检查指标怎么看

先看**采样时孕周、单位、检验方法、孕期参考区间和历次趋势**，再看箭头。正常参考范围、筛查界值、诊断条件、治疗目标不是同一个概念。

| 指标 | 意义 | 理解关键界值或结果 | 常见误读 |
| --- | --- | --- | --- |
| 血压 | 识别妊娠相关高血压风险 | 收缩压≥140 **或**舒张压≥90mmHg应规范复测并联系医生评估；≥160 **或**≥110mmHg属于严重范围，应立即就医，不能在家等待数小时“凑确诊”。[血压共识][s-bp] | 不是必须高压、低压同时超标；一次升高需评估，不等于已完成诊断 |
| 尿蛋白 | 配合血压及症状评估肾脏/子痫前期风险 | 阳性需要结合定量、采样及其他检查；没有蛋白尿，也不能排除有器官损伤表现的子痫前期。[血压共识][s-bp] | “血压高但尿蛋白阴性就安全”不成立 |
| 血红蛋白Hb | 反映是否贫血 | 国内2026共识仍以 **Hb<110g/L** 为妊娠期贫血界值；缺铁只是贫血原因之一。[血液管理共识][s-anemia] | 不直接照搬非孕期女性参考值，也不把国外孕中期105g/L界值与国内标准混用 |
| 血清铁蛋白SF | 帮助判断铁储备 | 国内共识以 **SF<20μg/L** 提示铁缺乏；结合Hb等判断是否缺铁性贫血。炎症可能影响SF解释。[血液管理共识][s-anemia] | Hb正常不一定铁储备充足；贫血也不一定只需补铁 |
| 血小板、肝肾功能 | 发现血液、肝肾及妊娠并发症线索 | 新出现下降/升高要看程度、趋势和症状；血压异常伴这些变化需及时评估。[血压共识][s-bp] | 不能把所有异常解释为“怀孕都会这样” |
| TSH、FT4、TPOAb | 评估甲状腺功能及自身免疫状态 | 优先用孕期及检测方法对应的参考区间，结合FT4、抗体、病史解读；不要只用TSH是否超过2.5作统一诊断。[甲状腺指南][s-thyroid] | 疾病诊断界值、已治疗者目标和普通孕妇筛查界值不能混为一谈 |
| ABO、RhD与不规则抗体 | 为母胎血型相关风险及输血准备提供信息 | RhD阴性者需要明确抗体状态及后续监测；孕约28周的预防、出血/操作后的处理及产后安排由专科制定。[Rh管理综述][s-rh] | RhD阴性不等于已经致敏，也不等于每个人都按同一方案用药；不能只理解为“第二胎才有风险” |
| HBsAg、梅毒/HIV初筛 | 发现需要确认、进一步评估或阻断的感染 | 看“初筛”还是“确认”、具体标志物与医生结论；检测阳性需及时进入相应流程。[三病方案][s-infection] | 初筛有反应不等于对疾病阶段和传染风险已作完整诊断 |

**例：**Hb为108g/L，而SF仍未测，能提示需要贫血评估，但不能单凭这一项确定“就是缺铁”。反之，SF低而Hb尚正常，也值得和医生讨论铁储备与随访。这里不据化验值提供补铁、降压或甲状腺用药剂量。[血液管理共识][s-anemia]

### 日常血糖：先用医生给定的个体目标

**匿名情境：某位孕前已患糖尿病的孕妇，被医生要求日常餐后2小时＜7.0 mmol/L。这是该情境的个体目标，不能复制给所有读者。糖耐的8.5不是日常餐后控制上限。**

| 监测时点 | 常用孕期参考上限（mmol/L） | 使用方式 |
| --- | --- | --- |
| 空腹/餐前 | ＜5.3 | 按医嘱安排相应时点 |
| 普通餐后1小时 | ＜7.8 | 或按医嘱测2小时；不要求人人每餐两个时点都测 |
| 普通餐后2小时 | ＜6.7 | 参考值与个人医嘱有差别时，确认方式、时点和目标，不自行改药 |

依据：[2022专业指南第二部分](https://www.hnysfww.com/data/article/1646672977096677660.pdf)、[2026 ADA国内专业解读](https://cspm.cma.org.cn/index/news?id=3843)。这些是上限，不是越低越好。

餐后从第一口进餐计时。08:00开始吃，2小时值在10:00测，不从吃完开始。指尖、静脉血浆与CGM不能直接当作同一种检测。记录时间、数值、饮食、活动、用药及症状。[北京妇产医院](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jksh/202307/t20230727_3208506.html)

例如普通餐后2小时7.2，虽低于8.5，但超过该匿名情境中的＜7.0目标。单次结果不用于自行加药。多次超标或身体不适，应及时联系团队。

### 孕前糖尿病（PGDM）：独立随访路径

- 确认怀孕后尽早由产科与内分泌共同评估，核对所有孕前用药。首次产检完善眼底、肾功能及尿蛋白/白蛋白评估；已有肾病需更密切复查。[2022第一部分](https://www.hnysfww.com/data/article/1646875724677244415.pdf)
- HbA1c早、中、晚孕至少各一次。无明显低血糖时常以＜6.0%为理想参考，有低血糖倾向时可放宽至＜7.0%，由医生确定。它不能替代日常测量。
- 20周后动态评估生长。孕前或早孕控糖不佳者尤其关注胎儿中枢神经和心脏，讨论专科胎儿心超。控糖不佳或使用胰岛素者，晚孕超声常需每2–4周安排。国内指南建议PGDM32周起胎儿监护，其他高危因素可提前。[2022第二部分](https://www.hnysfww.com/data/article/1646672977096677660.pdf)
- 使用胰岛素等有低血糖风险药物时，＜3.9 mmol/L或有相关症状应执行低血糖方案。清醒可吞咽者约15g速效糖，15分钟复测；仍低则再次补糖。意识不清、抽搐或不能吞咽时拨打120，不喂食。不要等到3.3才处理。[浙大一院](https://www.zy91.com/content/default2/77/8478)
- 1型者尤其需要生病、呕吐和酮体检测方案。不能自行停基础胰岛素。持续呕吐、不能进食饮水、腹痛、呼吸深快、嗜睡或酮体升高，及时就医，不等某个极高血糖值。
- 早孕评估子痫前期风险，12周前后与医生确认预防方案。分娩前制定产后用药与监测方案。PGDM产后继续糖尿病管理；GDM产后4–12周OGTT路径不用于重新确诊已知孕前糖尿病。[2024指南第17–18章](https://files.sciconf.cn/master/50/33230/202501/20250120111901_47273.pdf)

### OGTT：未确诊糖尿病者的诊断路径


以下适用于通常在孕24–28周进行的**75g OGTT静脉血浆葡萄糖**，不是指尖血糖仪读数，也不是日常餐后血糖控制目标。[国家行业标准][s-ogtt]

| 采血时间 | 诊断界值 |
| --- | --- |
| 服糖前空腹 | ≥5.1mmol/L |
| 服糖后1小时 | ≥10.0mmol/L |
| 服糖后2小时 | ≥8.5mmol/L |

**对于尚未确诊孕前糖尿病、也未达到显性糖尿病诊断水平者，任一项达到或超过界值，即符合该检测方案的GDM判定标准，需要产科医生结合检查情况完成诊断与管理。**例如5.1、9.0、7.0mmol/L，空腹已经达到界值，并不是“三项都超才算”。明显升高、达到显性糖尿病标准的结果需另行鉴别分类，不能把所有孕期高血糖都只称为GDM；孕早期血糖异常和孕前已知糖尿病也有另外的评估路径。[国家行业标准][s-ogtt]、[孕期高血糖分类说明][s-hyperglycemia]

准备时，检查前连续3天正常饮食，不临时少吃主食；至少禁食8小时，按医院要求留取空腹血后饮用75g葡萄糖液，并完成1小时和2小时采血。通常要求约5分钟内饮完，计时以检验科流程为准。检查过程中若呕吐或明显不适，告诉医护人员，由其判断结果是否有效或如何重约。[OGTT准备说明][s-ogtt-prep]

## 四、胎儿筛查结果怎么看

### NT、唐筛、无创和羊穿各管什么

| 检查 | 重点指标或结论 | 能说明什么 | 不能说明什么 |
| --- | --- | --- | --- |
| NT等早期超声 | NT厚度、孕周、其他结构线索 | NT增厚可提示染色体、心脏及其他结构问题风险增加 | NT正常不能排除所有异常；增厚也不等于胎儿已确诊患病 |
| 血清学唐筛 | 21/18三体等风险比、AFP等经校正指标 | 把孕周、年龄、体重与血清指标整合成风险估计 | 不是从AFP/hCG单个高低直接诊断唐氏综合征 |
| NIPT | 21/18/13三体低风险、高风险或无结果 | 对目标三体风险进行筛查 | 不是确诊；低风险不能替代结构超声，也不能排除全部遗传病 |
| 绒毛/羊水取样后的检测 | 核型、CMA、特定基因检测等具体结论 | 对实际选择检测范围内的异常提供诊断信息 | “取了羊水”不等于所有染色体、基因和发育问题都已排除 |

依据：[2025血清学要点][s-serum]、[2025无创要点][s-nipt]、[NT专科说明][s-nt]、[生长异常遗传评估路径][s-growth]。

NT不能用一个全国统一的“合格线”自行判定。部分中心采用约3.0mm或对应高百分位提示增厚，也有不同阈值；应看当次孕周、测量条件、诊断中心标准及其他异常。**NT被标为增厚或伴结构异常时，应咨询产前诊断中心，不能把“补做一次无创低风险”当作问题全部解决。**[NT专科说明][s-nt]

血清筛查的风险比，分母越小通常风险越高：`1:100` 高于 `1:1000`。临界/高风险的划分以报告采用的方案为准，不在这里统一指定所有机构的切点。NIPT所谓“检出率很高”也不表示“高风险阳性后有同样高的患病概率”；检出率、阳性预测值和个人风险是不同概念。

NIPT无结果也不能当作低风险。胎儿游离DNA比例、样本等因素可能导致重新取样，由产科/遗传咨询决定重抽还是进一步诊断。扩展微缺失、性染色体等套餐不能与国家知情要点中21/18/13三体的标准目标混称为同等适用范围。[2025无创要点][s-nipt]

### 系统超声与生长报告

| 缩写/项目 | 意义 | 阅读方式 |
| --- | --- | --- |
| CRL | 头臀长 | 早孕核定孕周的重要依据，不用后期某一径线反复重算孕周 |
| BPD | 双顶径 | 头部径线之一；不能单凭它判断智力、性别或能否顺产 |
| HC | 头围 | 与同孕周标准比较，结合其他生长参数 |
| AC | 腹围 | 生长及营养状况评估的重要参数，需看孕周百分位与趋势 |
| FL | 股骨长 | 骨骼生长参数，不能由某次测量预测孩子成人身高 |
| EFW、P10/P50等 | 超声估测体重、同孕周百分位 | 看是否偏离生长曲线及是否伴血流、羊水等异常；估测并非出生后称重 |
| AFI或最大羊水暗区深度 | 不同羊水评估方法 | 先确认报告用哪一种和单位，不能共用同一套数值界限 |
| 胎盘位置、胎位 | 胎盘与宫颈口的关系、胎儿朝向 | 随孕周动态评估，后续复查与分娩方案由产科判断 |
| 脐动脉等血流 | 胎盘/胎儿循环线索 | 按孕周、测量血管和整体情况解读，不套固定“万能S/D正常值” |
| 结构筛查结论 | 已观察结构及显示受限部位 | 有“显示不清/检查未完成”时应问清补查；不能只看照片好不好看 |

缩写释义见[超声报告说明][s-biometry]；百分位、生长及血流评估见[2025胎儿生长共识][s-growth]；结构筛查局限见[国家2025超声要点][s-ultrasound]。上述阅读提示不提供逐孕周的“必须长到某厘米”表，避免忽视个体差异与测量误差。

**小于第10百分位是进一步评估的信号，不等于单凭一次超声就确诊病理性生长受限。**医生还要核实孕周、生长趋势、母体情况及胎盘/血流等因素。不能看到“偏小”就自行大量进补。[2025胎儿生长共识][s-growth]

系统超声正常仍不能保证检出所有异常；部分问题会在后期或出生后显现，指/趾、单纯腭裂、微小心脏缺损等也有检出限制。所谓三维、四维不能取代规范系统筛查或保证检查更全面。[国家2025超声要点][s-ultrasound]

### 胎心听诊和NST不是一回事

晚孕尤其足月评估常用的胎心基线范围为110–160次/分，但NST还看基线变异、加速、减速与宫缩关系。不能把“听到心跳”“某个瞬时数字正常”当成胎儿一定安全。反应性判读与孕周、记录时长等有关，报告可疑或无反应需由医生决定延长记录或进一步评估。[胎心数值说明][s-heart]、[胎监专业说明][s-nst]

胎动明显较平时减少或停止时，应及时联系产科/就医，不能因家用胎心仪听起来正常而拖延，也不先等喝冰水、果汁或达到某个固定次数再决定。[母体与胎动警讯][s-warning]

## 五、哪些属于按病史和风险增加的检查

| 情形或项目 | 如何纳入规划 |
| --- | --- |
| 甲状腺功能 | 2018普通保健框架与后续专病指南推荐不同；2019专病指南支持有条件机构在孕早期筛查TSH、FT4、TPOAb，最好更早。按医院与专病方案安排，不能简单说“所有人都必须全套”或“无症状一定不查”。[甲状腺指南][s-thyroid] |
| 地中海贫血/遗传病筛查 | 结合地区、血常规、家族史、既往胎儿情况；需要时安排伴侣检测和遗传咨询。[保健指南][s-general] |
| 子痫前期风险评估 | 首诊就告知高血压、肾病、自身免疫病、既往子痫前期及多胎等病史；是否加测其他指标和何时干预由医生制定。不是用一次尿蛋白取代全程血压随访。[血压共识][s-bp] |
| 胎儿超声心动图、宫颈长度、血流或额外生长监测 | 由既往病史、当次超声及早产/生长风险触发，常规系统超声不等于所有专科检查都已完成。[保健指南][s-general]、[生长共识][s-growth] |
| TORCH相关病原学 | 无症状孕妇不应将全套反复血清学作为必做打卡；有暴露、症状或胎儿异常时可针对性检查。单次抗体结果不能直接判断胎儿是否感染或决定妊娠结局。[保健指南][s-general] |
| hCG、孕酮反复检测 | 本规划不将其作为所有孕妇每次复诊的固定套餐；有早孕出血、位置/存活待明确或辅助生殖等情况时，按具体诊断路径使用，不能脱离超声和临床情况看单一数值 |
| 尿培养 | 与尿常规不同；有尿路症状、异常或风险时需医生评估。国内相关指南存在常规筛查策略差异，不直接照搬国外方案。[国内筛查策略讨论][s-urine] |
| RhD阴性及不规则抗体阳性 | 单独建立监测和预防计划；尤其出血、腹部外伤或侵入操作后，及时告知医生。[Rh管理综述][s-rh] |

既往剖宫产/子宫手术、多胎、辅助生殖、糖尿病、高血压、持续瘙痒、感染阳性、筛查高风险等都应主动告知，可能改变复查项目和频率。不能把疫苗接种、营养补充、检查和治疗混成一张人人相同的必做表。

## 六、预约与检查前准备

| 检查 | 预约时确认 |
| --- | --- |
| 首诊基础化验 | 本次是否含空腹血糖等需要空腹的项目；社区建册和医院建档各需什么材料 |
| NT、系统超声 | 是否提前预约；检查单名称、适宜孕周；腹部/阴道检查及膀胱准备是否有特殊要求 |
| 血清学筛查 | 抽血窗口、孕周依据、是否需携带超声及体重信息；空腹要求按该机构流程 |
| 单独NIPT抽血 | 通常不因NIPT本身要求空腹；若同日有其他空腹项目需合并安排。[医院说明][s-visit] |
| OGTT | 三天正常饮食、禁食时长、糖液领取、计时与三次抽血流程；用药和不适处理问检验科。[OGTT准备][s-ogtt-prep] |
| NST | 宽松衣服，按医院要求准备；不因做NST而刻意空腹。异常症状不要等计划检查。[机构说明][s-hospital] |
| GBS | 取样方式和结果时间，既往GBS菌尿/新生儿感染史，药物过敏史应提前告诉医生。[中国共识][s-gbs] |

带齐母子健康手册、既往报告/影像、准确孕周依据、病史和正在使用的药物/补充剂清单。长期药物不要因为要抽血自行停用，具体服药时间提前向医生确认。

**异常报告的处理：**先联系开单产科，说明孕周和报告结论；问清是否有转诊时限、是否要带原始影像/样本，以及补查后由谁再次解读。不要通过不断更换筛查套餐来拖延应做的诊断咨询。

## 七、不能等到下一次预约的情况

出现明显阴道出血或流液、持续/严重腹痛、严重头痛或视物异常、胸痛/呼吸困难、晕厥、单侧肢体红肿疼痛、胎动明显减少/停止，或严重呕吐无法进食饮水时，及时联系产科或急诊；严重情况拨打120。有伤害自己或宝宝的念头也应立即求助。这些情况不受“下一次产检还没到”的限制。[CDC警讯][s-warning]、[国内就医说明][s-hospital]
