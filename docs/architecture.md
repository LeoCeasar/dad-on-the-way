## 命名规则

公开文件格式：`阶段数字＋小写字母.中文主题.html`。

- 数字固定对应阶段；字母是该阶段文档的阅读顺序，不绑定固定主题。
- 同一编号只对应一份公开主文档。已发布编号保持稳定，新文档按下一可用字母追加。
- 文件名不用空格、版本后缀、日期、“最终版”或“(2)”。版本和核验日期保留在正文中。
- 分龄文件在主题后标注年龄，例如`3a.幼儿饮食与生活习惯_1至3岁.html`。边界解释以本规范为准。
- 内部资料沿用主文档编号，例如`0a.孕检双向核验记录.md`。
- 多份文档共用的内部资料可用`0bc`表示服务0b和0c；此规则不用于公开主文件。
- 不为尚未编写的内容创建空HTML或失效链接。规划名称只列在本规范中。
- 页内索引保持稳定，例如`I01`、`M01`、`concept-C01`。移动文档时同步更新相对路径。

```text
│   ├── source-map.md           # 文档、来源入口与审核记录的对应关系
│   ├── drafts/                 # Markdown底稿与正文草稿
│   ├── reviews/                # 核验、差异与修订记录
│   └── research/               # 后续独立检索日志、证据提取资料
├── assets/

│   └── references/            # 原始参考图与待核素材
├── archive/                   # 必须保留的旧版公开文档；当前无历史副本

```

根目录的README是当前入口。`index.html`作为未来可视化首页的预留名称，本次不创建。HTML继续保持现有离线阅读方式；仅目录整理不引入远程运行依赖。

## 维护要求

新增文档时先选阶段和未用编号，再确定正文范围。发布时同步README与[source-map](source-map.md)，记录来源、核验日期和适用限制。共用的医学规则优先链接主说明，避免各文档维护不同数值。

移动或更名后检查全部项目自有HTML和Markdown的相对链接、图片、页内索引及外部来源地址。第三方仓库不参与批量改写。历史审核记录仍标注原审核版本，目录迁移不伪装成重新完成医学核验。
