# 孕检 HTML 二次审核记录

审核日期：2026-11-01。对应文件：[孕检规划与指标图解](../../0a.孕期产检规划与指标解读.html)。

## 本次问题与处理

匿名审查情境：一位孕前已患糖尿病的孕妇，普通餐后2小时的医嘱目标为小于7 mmol/L，而页面突出展示8.5。该情境用于发现诊断界值与管理目标混淆的问题，不代表所有读者的病史或处方。

原页面的8.5是75g OGTT的诊断界值，数字本身正确。但页面把诊断界值画得突出，仅用小字排除家庭监测，容易误用。此次修订既纠正表达，也补齐原页面缺少的孕前糖尿病路径。

## 正向核验：从页面逐项查依据

| 项目 | 核验结论 | 页面修改 |
| --- | --- | --- |
| 75g OGTT，服糖后2小时≥8.5 | 属于规定条件下静脉血浆的GDM诊断界值。不是普通进餐后的治疗目标。[国家标准][ogtt] | 撤掉共同刻度条。改为独立时点表，列明适用对象、单位、采样和“等于也算”。 |
| 日常血糖目标 | 中国2022指南：空腹/餐前＜5.3；餐后1小时＜7.8，或2小时＜6.7。2026 ADA国内解读与此一致。[2022第二部分][dm2]、[2026解读][ada] | 新增日常目标卡。明确这是常用参考上限，不是个人处方，也不是越低越好。 |
| 匿名情境的餐后2小时＜7.0 | 是情境中的个体医嘱，无法仅凭通用指南判错。 | 放在页面开头并注明匿名情境。保留该情境的目标。提醒复诊确认测量方式、计时和目标；不擅自改为6.7。 |
| 普通餐后2小时7.2 | 大于该匿名情境的目标，即使小于8.5，也不能算达标。单次读数不足以决定自行加药。 | 新增场景示例，明确不是个人实测值。 |
| 餐后计时 | 北京妇产医院明确从进食第一口开始。[官方患者教育][time] | 新增08:00→09:00/10:00计时图。说明1小时和2小时按方案选择。 |
| 指尖、静脉、CGM | 用途、采样和时序不同。CGM需结合自我监测解释。[2022第二部分][dm2]、[2026解读][ada] | 分列方法。不把CGM曲线直接用于OGTT诊断。 |
| 用药者低血糖＜3.9；妊娠章节＜3.3 | 2024同一指南第17章与第18章存在口径差异。不能说3.3已废止，也不能把3.3–3.8画成安全区。[2024原刊][cds] | 用药者＜3.9或有症状时执行低血糖方案。不等到3.3才处理。清醒可吞咽者约15g速效糖，15分钟复测。[浙大一院][hypo] |
| Hb＜110g/L、SF＜20μg/L | 符合国内2026共识。Hb与铁储备不是同一指标。[2026共识][anemia] | 保留数值。增加“异常判断界值”标签，避免被当成治疗目标或完整正常范围。 |
| NT、唐筛、NIPT及结构超声窗口 | 2025国家附件支持原窗口。未因旧科普的简写改动。[超声][ultra]、[血清][serum]、[NIPT][nipt] | 增加正式名、俗称、方法与用途对照。保留精确窗口。 |
| 20周同时高亮多个项目 | 都在时间窗内，不等于本周全部必做。 | 周提示分成常见窗口、咨询后选择的筛查、有指征的安排。强调羊穿不是人人必做。 |
| “检查完成”与“正常” | 完成观察、未见明显异常、显示受限是不同结论。[国家超声要点][ultra] | 拆成三条解释。提示显示受限时问清补查。 |
| P10 | 是与同孕周参考人群比较的位置，不是发育完成比例。[生长共识][growth] | 增加直白释义。保留单次小于P10不等于直接确诊FGR的说明。 |

| 结构及心脏评估 | 同上，7-7，印刷84页 | 孕前或早孕控糖不佳者尤其关注；讨论专科心超。不编造所有患者统一的必做孕周。 |
| 20周后动态看生长；晚孕超声及胎儿监护 | 同上，7-8、7-12，印刷84–85页 | 控糖不佳或用胰岛素者晚孕每2–4周超声。PGDM从32周开始胎儿监护，其他高危可提前。具体频率由团队确认。 |
| 子痫前期风险与药物审核 | [2022第一部分][dm1]、[2024指南][cds]、[2026专业解读][ada] | 早孕评估，12周前后确认是否需预防。不提供自行启用阿司匹林或调整降糖药的步骤。 |
| 生病、呕吐和酮体方案 | [2024指南][cds]、[NICE NG3][nice] | 不用某个高血糖大数字作为唯一急诊门槛；1型尤其不能自行停基础胰岛素。 |
| PGDM与GDM产后不同路径 | [2024指南][cds]，印刷84页 | PGDM继续糖尿病管理；GDM通常产后4–12周OGTT。不能要求已确诊孕前糖尿病者靠OGTT重新确诊。 |

上述“双向”是两个方向的覆盖核查，不等于每条都有两项独立临床研究。国家附件、转载原刊、同一指南的解读不能重复计算为独立证据。

## 冲突与访问限制

- **小红书：未完成原始图文核验。**搜索页/探索页受登录或读取限制。未读到可追溯的完整笔记正文和图片。二手转载或AI摘要不作为小红书原始证据，也不用于决定医学数字。当前页面的俗称与流程用公立医院患者教育交叉核对；不能声称已覆盖用户看过的小红书笔记。
- [北京妇产医院2024攻略][names]可用于“大排畸”“小排畸”等名称，但其中GBS时间及过期妊娠表述没有整表照搬。GBS仍采用国内专项共识35–37周。
- [北京妇产医院2023血糖科普][time]用于计时与日常监测说明。未采用其旧式严重高血糖数字作为等待就医的门槛，也未把空腹下限3.3设为家庭安全线。
- [NICE NG3][nice]的餐后2小时目标为＜6.4，与中国常用＜6.7不同。这是来源口径差异，不混合为中国统一数值。页面引用其眼底、肾脏、酮体与产后原则作交叉验证。
- 国家网页与PDF下载可能受访问方式限制。2022两部分原刊PDF已直接下载并核读相关条款；2024原刊由专项复核直接下载核读。页面保存原始链接与出版信息，没有把转载平台说成指南发布机构。
- 本次为资料与界面审核，不是临床专家会诊，也没有审核个人检验报告或药物剂量。
